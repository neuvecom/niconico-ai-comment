## Step 1: モック弾幕描画の実装

### 実施内容
Plan.md の Step 1「モックデータをもとに、実際の動画プレイヤー上にコメントを滑らかに流す最低限のフロントエンド機能」を実装。

### 変更
- `manifest.json`: MV3 定義。`nicovideo.jp/watch/*` に content script（`data/mock-comments.js` → `content.js`）と `content.css` を注入。
- `data/mock-comments.js`: `time / text / user / color` を持つモックコメント 15 件。3 ペルソナ（fan / tsukkomi / expert）。
- `content.js`: 弾幕エンジン本体。
  - `<video>` を MutationObserver で検知。
  - 透過オーバーレイを video の表示矩形へ毎フレーム追従（フルスクリーン・リサイズ対応）。
  - `requestAnimationFrame` で `currentTime` を監視し時刻同期でコメント出現。シーク（大きな時刻ジャンプ）と一時停止を検出。
  - 全弾幕を等速にしてレーン内追突を回避。レーンは高さに応じて動的計算。
- `content.css`: 透過・pointer-events none・縁取りテキストのスタイル。
- `README.md`: インストール手順・ファイル構成・データ形式を追記。

### 検証
- `node --check` で `content.js` / `data/mock-comments.js` の構文を確認。
- `manifest.json` を `JSON.parse` で検証。
- ブラウザでの実描画確認は未実施（ローカルで拡張を読み込んでの目視確認が必要）。
