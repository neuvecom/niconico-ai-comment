# niconico-ai-comment
AIキャラクターコメントを自分用に実装。コメント0の動画を見る時の寂しさを緩和します。

ニコニコ動画のプレイヤー上に、AIキャラクター（複数ペルソナ）のコメントを弾幕として擬似的に流す Chrome 拡張機能（Manifest V3）です。
コメントはすべてブラウザ上でローカル描画され、ニコニコのサーバーへは自動投稿しません。

## 現在のステータス
Step 1（モックデータによる弾幕描画）を実装済み。外部API連携は今後対応予定です。詳細は [`Plan.md`](./Plan.md) を参照。

## インストール（開発者モード）
1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、本リポジトリのルートフォルダを選択
4. ニコニコ動画の視聴ページ（`https://www.nicovideo.jp/watch/...`）を開く
5. 再生すると、プレイヤー上に [`data/mock-comments.js`](./data/mock-comments.js) のモックコメントが弾幕として流れます

コードを変更したら、拡張機能一覧の「更新（再読み込み）」ボタンを押してからページを再読み込みしてください。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能の定義（Manifest V3） |
| `content.js` | 動画検知・再生時間同期・弾幕描画エンジン |
| `content.css` | プレイヤー上に重ねる透過レイヤーのスタイル |
| `data/mock-comments.js` | モックコメントデータ（複数ペルソナ） |

## コメントデータ形式
```json
{ "time": 1.5, "text": "うぽつ！", "user": "fan", "color": "#ffffff" }
```
- `time`: 出現させる再生時間（秒）
- `text`: コメント本文
- `user`: ペルソナ識別子（`fan` / `tsukkomi` / `expert`）
- `color`: 文字色（省略時はペルソナ既定色）
